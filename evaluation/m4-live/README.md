# M4 live/native B1-B6 field benchmark

This is one provider-neutral field path for OpenAI Realtime and Gemini Live.
It does not select a production provider. Run the same scenario, guide,
language, device, build, network and repetition count for both providers.

## Controlled inputs

- B1-B6 utterances and checks remain canonical in
  `server/src/benchmark/realtimeVoiceBenchmark.ts`.
- B4 uses `mobile/assets/m4-road-noise-v1.wav`, a deterministic synthetic
  fixture generated by `generate-road-noise.mjs`; it contains no copyrighted
  source audio or recorded speech.
- Expected SHA-256: `6d7e534c3976e9a2b9cec8977bcd088e361e19ce580cebd78fe2f8a36a32ba2a`.
- Play B4 with the in-app control at fixed app volume `0.35`, with the phone at
  the same marked distance/orientation for both providers.
- Field driving can supplement but cannot replace this paired controlled run.

## Run order

For every guide/language combination, select a provider and B1-B6 in the
development-only panel. Tap Talk, perform the canonical script, close Talk,
and repeat the scenario at least three times. Then switch providers without
editing application data or rebuilding. Export the JSON artifact after both
provider runs.

The artifact contains controlled benchmark transcripts and approved M3 answer
text. It must not contain real user speech, raw microphone recordings, API
keys, tokens or device provisioning secrets. Ordinary `usage_events` remain
transcript-free.

## Cost

Provider usage counters are stored per trial. A cost decision is valid only
when the artifact has measured counters and a dated pricing snapshot. Missing
counters are marked unavailable rather than zero. Calculate cost/run,
cost/active voice minute and a 30-minute projection using the measured voice
duty cycle; label any substituted rate or unit conversion as a fallback
estimate.

## Security follow-up after M4

Split OpenAI, Gemini, VPS and GitHub credentials; move runtime values to GitHub
Secrets/server secret storage; rotate VPS/SSH credentials if they were ever
kept in a shared plaintext file. Never add their values to this directory.
